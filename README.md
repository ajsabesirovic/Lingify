# Lingify Translator

Lingify is a simple and efficient English-Serbian translator designed for quick and accurate translations. It features a user-friendly interface, translation history tracking, and additional resources for language learning.

## Live Demo

You can access the app here: **[Lingify](https://lingify.pages.dev/)**

## Installation (For Local Development)

1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/Lingify.git
   ```
2. Navigate to the project folder:
   ```sh
   cd lingify
   ```
3. Open `index.html` in your browser or use a local server for testing.
